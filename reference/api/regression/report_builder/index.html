    k4bench.regression.report_builder¶

    k4bench.regression.report_builder ¶

    Assemble one suite's nightly regression report from the EOS run history.

    Walks every (detector, platform, sample) triple of the suite's run tree below the WebEOS data URL (the same hierarchy the dashboard's sidebar cascades through — these triples have independent baselines and are never pooled), and never another suite's (see :mod:k4bench.layout). Pulls a trailing window of runs into the local cache, rebuilds the trend frames with :mod:k4bench.analysis.trend, attaches per-run reliability verdicts with :mod:k4bench.results.reliability_evidence, and runs the step detector in :mod:k4bench.regression.engine over every metric series.

    ReadsStopped ¶

    Bases: RequestException

    A read the report did not make: its reads had already stopped (see :class:ReportReads). A :class:requests.RequestException, so whatever handles an unanswered read handles this one too.

    ReportReads ¶

    ReportReads()

    Every read one report makes of EOS: retried, bounded, and stopped.

    A read the store does not answer is asked again after each of :data:READ_BACKOFF_S, within :data:READ_BACKOFF_BUDGET_S of waiting summed over the report. Only an unanswered read is retried: a 404 is an answer, and a local error — the cache disk full — is neither the store's fault nor fixed by asking it again. The last failure is raised.

    Reads stop for good once :data:READ_DEADLINE_S has passed since this object was made, or once :data:READ_BREAKER_TRIPLES triples in a row have failed (:meth:triple_read, :meth:triple_failed). After that every read raises :class:ReadsStopped without a request, so a sustained outage costs the report a bounded time and the triples it did not reach are still named. One instance spans a report and any rebuild of it (the outage report), so the bound is the job's rather than each build's.

    PredecessorRuns dataclass ¶

    PredecessorRuns(detector: str, platform: str, frames: dict[str, DataFrame | None], reliability: dict[str, bool | None], hosts: dict[str, HostFact] = dict(), machines: dict[str, str] = dict(), run_dirs: tuple[str, ...] = ())

    One run group's predecessor frames — a replaced platform's or a replaced detector config's — whose series this group's series continue (see :mod:k4bench.regression.lineage).

    Kept apart from the group's own frames and joined per metric series only: everything else read off those frames — tonight's release, the CI run, the config roster, failures, region timings — is a statement about this group, which a predecessor row would answer wrongly.

    Coverage ¶

    Bases: str, Enum

    What a report says about a benchmark fan-out (:func:fanout_coverage).

    COVERED — the fan-out uploaded a run judged by this report. HISTORY_ONLY — every triple was read and the fan-out appears only in the history of older releases filed on the same night. ABSENT — every triple was read and none came from it: it uploaded nothing, which is tonight's outage. UNKNOWN — an unread triple could hold a run to judge for this fan-out.

    def unjudged_value_verdicts(
    *,
    suite: str,
    detector: str,
    platform: str,
    sample: str,
    frames: dict[str, pd.DataFrame | None],
    tonight: str,
    already: set[tuple[str, str, str | None]],
    tonight_key: str | None = None,
) -> list[MetricVerdict]:
    """Raw metric values for *tonight*'s run as unjudged ``UNKNOWN`` verdicts.

    Two different things end up here. The engine skips unreliable runs (they
    must not pollute baselines or flags), so their metrics get no verdict and
    their values would never reach the report the dashboard's Overview tab
    reads — leaving that tab unable to plot them even with "Exclude unreliable
    runs" off. And each source's
    :attr:`~k4bench.regression.catalog.MetricSource.reported_only` metrics are
    never judged on any night by design, but are still worth being able to
    look up.

    Either way this records tonight's raw value for every config's metric of
    *suite*'s sources (*frames*, by source name) not *already* judged —
    ``(label, metric, sub_detector)`` — marked ``UNKNOWN`` (never a flag), so
    the value is preserved for display. A normally-judged run is already
    covered. Only whole-job metrics are recorded: a component's history is read
    from the runs by every view that draws it.

    Tonight's run is the one *tonight_key* names, by default the newest
    release filed under *tonight* (see
    :func:`~k4bench.analysis.loader.newest_run_key`).
    """
    out: list[MetricVerdict] = []
    if tonight_key is None:
        tonight_key = newest_run_key(list(frames.values()), tonight)

    def _emit(df: pd.DataFrame | None, source: MetricSource) -> None:
        if df is None or df.empty:
            return
        df = source.job_rows(df)
        tonight_rows = df[run_keys(df) == tonight_key]
        metrics = {**source.judged, **source.reported_only}
        for label in sorted(tonight_rows["label"].dropna().unique()):
            row = tonight_rows[tonight_rows["label"] == label]
            for metric, family in metrics.items():
                if metric not in row.columns or (str(label), metric, None) in already:
                    continue
                val = row[metric].iloc[0]
                if pd.isna(val) or not math.isfinite(float(val)):
                    continue
                reported_only = metric in source.reported_only
                out.append(
                    MetricVerdict(
                        detector=detector,
                        platform=platform,
                        sample=sample,
                        label=str(label),
                        metric_family=family,
                        metric=metric,
                        sub_detector=None,
                        run_id=tonight,
                        run_date=_measured_release(row, tonight),
                        value=float(val),
                        baseline_median=None,
                        baseline_mad=None,
                        pct_change=None,
                        z_score=None,
                        severity=Severity.UNKNOWN,
                        direction=Direction.NONE,
                        unjudged=(
                            Unjudged.REPORTED_ONLY if reported_only else Unjudged.UNRELIABLE_HOST
                        ),
                        reason=(
                            REPORTED_ONLY_REASONS.get(metric, REPORTED_ONLY_REASON)
                            if reported_only
                            else UNRELIABLE_HOST_REASON
                        ),
                    )
                )

    for source in sources(suite):
        _emit(frames.get(source.name), source)
    return out

    evaluate_group_series(*, suite: str, detector: str, platform: str, sample: str, frames: dict[str, DataFrame | None], reliability: dict[str, bool | None], hosts: dict[str, HostFact] | None = None, predecessor: PredecessorRuns | None = None, machines: dict[str, str] | None = None) -> dict[SeriesId, list[MetricVerdict]]

    def evaluate_group_series(
    *,
    suite: str,
    detector: str,
    platform: str,
    sample: str,
    frames: dict[str, pd.DataFrame | None],
    reliability: dict[str, bool | None],
    hosts: dict[str, HostFact] | None = None,
    predecessor: PredecessorRuns | None = None,
    machines: dict[str, str] | None = None,
) -> dict[SeriesId, list[MetricVerdict]]:
    """Run the step detector over every judged metric series of one run group
    of *suite*: each of its sources' (:func:`~k4bench.regression.catalog.sources`)
    judged metrics, per config, and per config and component where the source
    lists components. *frames* holds each source's frame by name. Region
    timings are not walked.

    Returns the **full verdict series** per :class:`SeriesId` — the nightly
    report takes each series' verdict for the report night, while the
    dashboard drill-down and the retrospective threshold validation consume
    the whole walk.

    *predecessor* (from :func:`predecessor_runs`) is the replaced platform or
    detector config this one succeeds: each series is walked with the
    predecessor's matching series in front of it, so a migration or version
    switch is judged like any other step. Only verdicts for this group's own
    runs are returned. Omitted — the normal case — each series is its own
    history alone.

    *hosts* (from :func:`~k4bench.regression.history.host_facts`) names the
    machine behind each run, and only reaches the history tails attached to
    confirmed verdicts; it never enters the judgement itself. Omitted, the tails
    simply carry no host. *machines* (from :func:`cpu_models`) does: a series
    re-anchors where its CPU model changes. Omitted, no change is seen.

    Every configuration is judged on what it measured. A night where the whole
    run group moved together therefore reports each config's own move, rather
    than one synthetic finding standing in for all of them.
    """
    out: dict[SeriesId, list[MetricVerdict]] = {}

    all_hosts = {**(predecessor.hosts if predecessor else {}), **(hosts or {})}

    def _walk(
        df: pd.DataFrame, metrics: dict[str, str], before_df: pd.DataFrame | None,
        component: str | None,
    ) -> None:
        labels = sorted(df["label"].dropna().unique())

        for metric, family in metrics.items():
            if metric not in df.columns:
                continue
            for label in labels:
                name = str(label)
                sid = SeriesId(detector, platform, sample, name, family, metric, component)
                own = _series_history(df, df["label"] == label, metric, reliability, machines)
                history = _continued_history(own, predecessor, before_df, name, metric, sid)
                verdicts = _with_history(
                    history, evaluate_series(history, series=sid), all_hosts,
                )
                own_runs = set(own["run_id"])
                verdicts = [
                    _with_endpoint_series(v, own_runs, predecessor)
                    for v in verdicts if v.run_id in own_runs
                ]
                if verdicts:
                    out[sid] = verdicts

    for source in sources(suite):
        df = frames.get(source.name)
        if df is None or df.empty:
            continue
        before_df = predecessor.frames.get(source.name) if predecessor is not None else None
        _walk(
            source.job_rows(df), source.judged,
            source.job_rows(before_df) if before_df is not None else None, None,
        )
        if not source.component_judged:
            continue
        before_components = (
            source.component_rows(before_df) if before_df is not None else None
        )
        for component, rows in source.component_rows(df).groupby(COMPONENT, sort=False):
            _walk(
                rows, source.component_judged,
                before_components[before_components[COMPONENT] == component]
                if before_components is not None else None,
                str(component),
            )

    return out

        partial(
            _fetch_run_dirs, data_url, suite, cache_dir, detector, platform, sample,

    candidates = predecessor_series(detector, platform, suite)

        suite, detector, platform, sample, run_dirs,
        predecessor=partial(
            _fetch_predecessor, data_url, suite, cache_dir, candidates, sample,
            fetch_window_runs=fetch_window_runs, as_of=as_of, reads=reads,
        ) if candidates else None,
    )

    def group_report_from_run_dirs(
    suite: str,
    detector: str,
    platform: str,
    sample: str,
    run_dirs: tuple[str, ...],
    *,
    predecessor: Callable[[], PredecessorRuns | None] | None = None,
) -> RunGroupReport | None:
    """Build one triple's report from already-local run directories of
    *suite* (ordered oldest → newest; each directory's name is its nightly
    date), judging what the suite's sources say it is judged on.

    *predecessor* loads the platform or detector config this one replaced,
    whose series this group's continue; it never contributes a verdict, a
    release, a failure or a timing. It is loaded for every replay, because a series' detection
    state can depend on the nights it continues however long ago they were.
    """
    if not run_dirs:
        return None
    # Tonight is the newest date's run, and of two releases benchmarked on that
    # date the newer: the other re-measured a release the series already holds.
    newest = max(Path(d).name for d in run_dirs)
    tonight_dir = max(
        (Path(d) for d in run_dirs if Path(d).name == newest), key=run_dir_identity,
    )
    tonight, tonight_release = run_dir_identity(tonight_dir)
    tonight_meta = parse_run_dir(tonight_dir)
    frames = _frames(suite, run_dirs)
    results_df = frames[RESULTS]
    machine_df = build_machine_info_trend(run_dirs)
    reliability = run_reliability_map(results_df, machine_df)
    before = predecessor() if predecessor is not None else None
    group = _group_report_from_frames(
        suite, detector, platform, sample,
        frames=frames, reliability=reliability, tonight=tonight,
        hosts=host_facts(machine_df),
        configured_labels=tonight_meta["configured_labels"],
        predecessor=before,
        machines=cpu_models(machine_df),
        tonight_key=run_key(tonight, tonight_release),
    )
    if group is None:
        return None
    # A night that wrote no result CSV has no provenance in its (absent) rows;
    # run_info still names the stack that failed, the CI run that ran it and
    # the geometry it loaded. The CI run is what ties the night to its batch
    # (_same_batch, report_covers_run): without it a fan-out whose every job
    # failed before writing a CSV reads as one that uploaded nothing.
    if not group.k4h_release:
        group.k4h_release = tonight_meta["k4h_release"] or ""
    if not group.github_run_url:
        group.github_run_url = tonight_meta["github_run_url"] or None
    if not group.geometry_path:
        group.geometry_path = tonight_meta["xml_path"] or ""
    group.history_run_urls = tuple(
        url
        for d in run_dirs
        if Path(d).name == tonight and Path(d) != tonight_dir
        and (url := parse_run_dir(Path(d))["github_run_url"])
    )
    return _DECOMPOSITIONS[suite](
        group, run_dirs, judgeable_config_keys(results_df), predecessor=before,
    )

    def build_nightly_report(
    data_url: str,
    suite: str,
    cache_dir: str | None = None,
    *,
    fetch_window_runs: int = FETCH_WINDOW_RUNS,
    as_of: str | None = None,
    night: str | None = None,
    reads: ReportReads | None = None,
) -> NightlyReport:
    """Build *suite*'s cross-detector report for the most recent nightly.

    The report night is the newest run date seen across all triples. A triple
    dated earlier is still reported normally when its CI run says it came from
    the report night's own batch, whatever the gap between the two dates (see
    :func:`_same_batch`); for a night whose runs carry no CI run at all, a lag
    of up to :data:`SAME_BATCH_LAG_DAYS` stands in for that. Anything else gets
    a *missing run* job failure (a hard crash uploads nothing, so absence is
    itself the failure signal) — unless it is stale by more than
    :data:`MISSING_RUN_GRACE_DAYS`, in which case it is treated as retired and
    dropped.

    *as_of* truncates every triple's history to runs on or before that night
    (see :func:`build_group_report`), making the report night the newest run
    ≤ *as_of* — the historical-backfill seam. *night* reports a night newer
    than every run found, as one missing run per triple (see
    :func:`_finalize_report`) — the outage seam.

    Every read goes through *reads* (:class:`ReportReads`; a fresh one when
    ``None``): strict, retried, and bounded in time for the whole report.
    Discovery — which triples exist — comes first and raises when the store
    still does not answer, failing the whole report: a triple discovery missed
    could not even be named as not judged. A triple whose own runs cannot be
    read, whose report cannot be built from them, or that was not reached
    before reads stopped is reported as not judged
    (:attr:`RunGroupReport.unread`) and the rest of the report stands.
    """
    reads = reads or ReportReads()
    triples: list[tuple[str, str, str]] = []
    for detector in reads(partial(list_detectors, data_url, suite), suite):
        for platform in reads(
            partial(list_platforms, data_url, suite, detector), detector,
        ):
            stack_samples = reads(
                partial(scan_stack_samples, data_url, suite, detector, platform, strict=True),
                f"{detector}/{platform}",
            )
            triples += [
                (detector, platform, sample)
                for sample in sorted({s for ss in stack_samples.values() for s in ss})
            ]

    groups: list[RunGroupReport] = []
    for detector, platform, sample in triples:
        try:
            group = build_group_report(
                data_url, suite, cache_dir, detector, platform, sample,
                fetch_window_runs=fetch_window_runs, as_of=as_of, reads=reads,
            )
        except ReadsStopped as exc:
            _log.warning("build_nightly_report: not reading %s/%s/%s — %s",
                         detector, platform, sample, exc)
            group = _unread_group(detector, platform, sample, exc)
        except Exception as exc:
            _log.exception(
                "build_nightly_report: not judging %s/%s/%s", detector, platform, sample,
            )
            if isinstance(exc, requests.RequestException):
                reads.triple_failed()
            group = _unread_group(detector, platform, sample, exc)
        else:
            reads.triple_read()
        if group is not None:
            groups.append(group)

    return _finalize_report(groups, suite, night=night)

    def build_nightly_report_local(
    data_dir: str,
    suite: str,
    *,
    fetch_window_runs: int = FETCH_WINDOW_RUNS,
    as_of: str | None = None,
    night: str | None = None,
) -> NightlyReport:
    """Like :func:`build_nightly_report`, but over a local directory tree with
    the same layout as EOS (:mod:`k4bench.layout`)
    (used by the integration test and for offline dry-runs; no network).
    *as_of* truncates each sample's runs the same way, and *night* reports an
    outage night the same way."""
    root = Path(data_dir)
    groups: list[RunGroupReport] = []

    def _window(run_paths: list[Path]) -> tuple[str, ...]:
        # Ordered by date, then release directory, as the remote window is.
        return tuple(
            str(p) for p in sorted(run_paths, key=lambda p: (p.name, p.parent.parent.name))
            if as_of is None or p.name <= as_of
        )[-fetch_window_runs:]

    # Every series first: a successor continues its predecessor's runs, which
    # can live under another platform or another detector config.
    # Each sample's run dirs are collected across all stacks.
    per_series: dict[tuple[str, str], dict[str, list[Path]]] = {}
    for run in iter_run_dirs(root, suite):
        per_sample = per_series.setdefault((run.detector, run.platform), {})
        per_sample.setdefault(run.sample, []).append(run.path)

    def _predecessor(detector: str, platform: str, sample: str) -> PredecessorRuns | None:
        for candidate in predecessor_series(detector, platform, suite):
            run_dirs = _window(per_series.get(candidate, {}).get(sample, []))
            if (runs := predecessor_runs(suite, *candidate, run_dirs)) is not None:
                return runs
        return None

    for (detector, platform), per_sample in per_series.items():
        for sample, run_paths in sorted(per_sample.items()):
            group = group_report_from_run_dirs(
                suite, detector, platform, sample, _window(run_paths),
                predecessor=partial(_predecessor, detector, platform, sample)
                if predecessor_series(detector, platform, suite) else None,
            )
            if group is not None:
                groups.append(group)
    return _finalize_report(groups, suite, night=night)

    def report_covers_run(report: NightlyReport, run_id: str) -> bool:
    """Whether *run_id*'s benchmark jobs produced any of this report's runs.

    def fanout_coverage(report: NightlyReport, run_id: str) -> Coverage:
    """Whether *report* covers the fan-out *run_id*, and whether it can tell.

    An unread triple carries no CI run (:attr:`RunGroupReport.unread`), so
    :func:`report_covers_run` alone would read a fan-out whose every upload
    sits in an unreadable tree as one that uploaded nothing.
    """
    if report_covers_run(report, run_id):
        return Coverage.COVERED
    if any(g.unread for g in report.groups):
        return Coverage.UNKNOWN
    if report_holds_run_as_history(report, run_id):
        return Coverage.HISTORY_ONLY
    return Coverage.ABSENT
